# TADKEERA (تذكرة) - QR Code Event Ticket Management System

TADKEERA is a professional Android application designed for managing event tickets using QR codes. It features a complete offline-first architecture for reliable scanning in various event environments.

## 📱 Features
- **Event Management**: Create and manage multiple events with custom details.
- **Ticket Design**: Custom ticket layouts with draggable QR codes and text elements.
- **Ticket Issuance**: Batch generation of unique QR codes and PDF tickets.
- **Offline Scanner**: High-performance QR scanner with duplicate detection and offline database validation.
- **Data Export/Import**: Manage guest lists via CSV.

## 🛠 Tech Stack
- **Language**: Kotlin
- **UI Framework**: Jetpack Compose
- **Architecture**: MVVM + Clean Architecture
- **Database**: Room (SQLite)
- **Dependency Injection**: Hilt
- **Asynchronous**: Coroutines + Flow
- **Scanning**: Google ML Kit Barcode Scanning
- **PDF Generation**: iTextPDF

## 🚀 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/tadkeera/tadkeera-qrcode.git
   ```
2. Open the project in **Android Studio Hedgehog** or newer.
3. Wait for Gradle sync to complete.
4. Run the application on an emulator or a physical device (Android 7.0+).
